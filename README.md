# Crown of Farmland

A turn-based strategy game implemented in Java, featuring a command-line interface and a computer-controlled opponent.

Developed independently as a university programming project at the Karlsruhe Institute of Technology (KIT), based on a provided game specification.

## Features

- Two opposing teams on a 7 × 7 game board.
- Unit placement, movement, blocking, and combat.
- Unit combinations governed by compatibility rules.
- Management of player health, hands, and unit decks.
- A computer-controlled opponent using predefined decision rules and weighted random selection.
- Loading of unit definitions and deck configurations from text files.
- Command-line interaction with input validation and error reporting.
- Seeded randomisation for reproducible game behaviour.

## Technologies and Concepts

- Java
- Game-state modelling and management
- Rule-based decision logic
- Weighted random selection
- File parsing and input validation
- Command-line interaction
